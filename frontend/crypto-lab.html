ChaCha20
Stream Cipher · Symmetric
Designed by Daniel J. Bernstein (2008). A 256-bit stream cipher built on ARX (Add-Rotate-XOR) operations. No S-boxes, no branches — pure arithmetic. Google adopted it for TLS on mobile where AES hardware acceleration is absent.

SHA-3 / Keccak
Hash Function · Sponge Construction
Selected as NIST SHA-3 standard in 2012 after a 5-year competition. Completely different construction from SHA-1/SHA-2 (Merkle-Damgård). Uses a sponge construction: absorb data into a state, then squeeze output. Immune to length-extension attacks by design.

✓ No Length Extension
Sponge construction absorbs capacity bits that are never exposed. Attacker cannot resume the internal state from the digest alone.
✓ Structurally Different from SHA-2
If SHA-2 is ever broken, SHA-3 remains unaffected. Diversity in construction is a feature.
⚠ Slower Than SHA-256 in Software
Without dedicated hardware, SHA-3 is ~30–50% slower than SHA-256. This is acceptable for most use cases.
HMAC-SHA256
Message Authentication Code · Keyed Hash
HMAC (Hash-based MAC) defined in RFC 2104. Wraps any hash function with a secret key in a double-hash construction: HMAC(K,m) = H((K⊕opad) ∥ H((K⊕ipad) ∥ m)). This is the exact algorithm protecting every request in your ZeroTrust system.

Ed25519
Digital Signature · Edwards Curve ECC
Designed by Bernstein et al. (2011). Uses Edwards curve over GF(2²⁵⁵-19). Only 32-byte keys and 64-byte signatures, yet provides ~128-bit security equivalent. Used by OpenSSH, TLS 1.3, Signal Protocol, and most modern systems replacing RSA.
RFC 8032 Deterministic Signatures ~128-bit Security Twisted Edwards Curve

✓ Deterministic Signatures
Nonce r = H(private_key, message). No random number generator involved at signing time — eliminates Sony PS3-style nonce reuse catastrophes.
⚠ Shor's Algorithm Threat
A sufficiently powerful quantum computer can solve the discrete logarithm problem on elliptic curves in polynomial time, breaking Ed25519 entirely.
RSA-2048
Asymmetric Encryption · Integer Factorization
Rivest, Shamir, Adleman (1977). The oldest widely-used public-key algorithm. Security rests on the hardness of factoring the product of two large primes. 2048-bit keys provide ~112-bit security — adequate today but being phased out in favor of ECC-based schemes like Ed25519.

✗ Shor's Algorithm
A 4096-qubit quantum computer can factor RSA-2048 modulus in hours using Shor's algorithm. Timeline: estimated 10–20 years.
⚠ Bleichenbacher Attack (PKCS#1 v1.5)
Padding oracle attack on RSA-PKCS1-v1.5 encryption. Mitigated by using OAEP padding. Your ZeroTrust system should use RSA-OAEP if RSA is used.
⚠ Timing Side-Channel
Modular exponentiation timing can leak private key bits without blinding. Well-implemented libraries use Montgomery blinding.
